# simple-ip-triage

Python based automation script designed to reduce alert fatigue
instead of spending excessive time manually checking suspicious IP addresses generated by firewall logs this script consumes a raw text file of extracted IP addresses (ips.txt), automatically queries the VirusTotal v3 API, extracts the malicious detection count, and outputs a clean triage_results.csv file for easy analyst review

Note: script includes intentional 16 second sleep intervals to handle the standard 4 requests per minute limit imposed by the free VirusTotal API
